# trywhichway.com

The intro site for WhichWay, the New York City subway assistant for iPhone: one page of large screens, the two
films and the way to ask for a TestFlight invite. Static HTML and CSS, served by GitHub Pages at
https://trywhichway.com (the `CNAME` file). The screens, films and copy come from the WhichWay page on
parametric.space; the app itself lives in the mta-delay-insights repository (`ios/WhichWay`).
